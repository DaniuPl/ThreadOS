About it

Each branch is a thread and each commit a knot on it, so a merge looks like what it is: two threads becoming one. Stage what you changed, write why, commit and push without leaving the window. It reads and writes ordinary git repositories, so the command line and Strand can take turns.

New in 1.2

  • Side threads for a branch you only want to look at
  • Push and pull show their progress on the shuttle
