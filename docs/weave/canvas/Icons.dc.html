Icons

One family for every program: a tile in the program's dye with the grain on it, one white drawing in a single stroke, and the thread along the bottom - the same thread the loom has.

{{a.label}}

How one is made

  • 48 grid, drawing inside 10 to 38
  • One stroke, 3 at 64 px; heavier when small
  • Corners 26 % of the side
  • The thread at 42.5, in a light tint
  • Fill only for knots: a commit, a slider's grip

For the kernel

The desktop draws today's icons in code (ART_* in kernel/desktop.c). These are lines and circles only, so they go the same way: gfx_line16 and gfx_disc16 on a rounded tile, at any size, with no picture files.

Linen and Night use the same tiles: the dyes are strong enough for both grounds.
