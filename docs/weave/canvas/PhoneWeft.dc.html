How the compositor draws a frame

Every window draws into memory of its own. The desktop only copies: it takes what changed since the last frame, lays the windows over the wallpaper from the back to the front, and hands the result to the screen in one go.

There is no graphics card doing this for us, so every effect is paid for by the processor. That is why Weave has no blur: a grain tile is copied, never computed.
