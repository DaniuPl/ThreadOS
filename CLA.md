## How to accept

In your first pull request, add one row to the table in
[CLA-SIGNATURES.md](CLA-SIGNATURES.md):

```
| your-github-login | Your Full Name | 2026-11-19 | 1.0 |
```

Use the GitHub account the pull request comes from, your real name, the
date, and the version of this agreement. By adding the row You accept
this agreement for every Contribution You submit from then on, until a
newer version is published. A check on every pull request (the `cla`
workflow) looks for the row and says what is missing.
